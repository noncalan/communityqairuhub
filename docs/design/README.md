# Дизайн и визуальные материалы

Отдельных исходников Figma/Canva или экспортированного brand kit в репозитории сейчас нет.

Текущая дизайн-система распределена так:

- `src/app/globals.css` — токены темы, глобальные стили и Tailwind CSS;
- `src/components/ui/` — UI primitives;
- `src/components/shared/` — бренд, навигационные ссылки и общие элементы;
- `components.json` — конфигурация shadcn;
- `public/og.png` — используемое Open Graph изображение;
- `src/app/favicon.ico` — favicon приложения.

Не кладите рабочие макеты в `public/`: всё внутри этой папки доступно по публичному URL. Исходники дизайна и спецификации следует хранить в этой папке, а только готовые web-assets — в `public/`.
