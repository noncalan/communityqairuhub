# Implemented feature inventory

Status meanings:

- **Implemented**: an end-to-end repository implementation exists for the stated behavior.
- **Partial**: useful live behavior exists, but an obvious part of the flow is a placeholder, prototype, or missing lifecycle step.
- **Not implemented**: no working live route/action/schema for the named capability was found.

Demo-only behavior is called out explicitly and is not counted as live implementation.

## Demo-only surfaces

When live mode is disabled, most Hub pages render components in `src/components/demo/` backed by `src/lib/data/mock.ts` and `src/lib/demo/demo-store.tsx`. Demo actions persist in `localStorage` under `qairu-hub-demo:v2`. These screens demonstrate intended interactions but do not write to Supabase and are not counted as live feature completion.
